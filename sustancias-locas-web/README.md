# Sustancias Locas — sitio corporativo académico

Sitio web estático para complementar las tareas 2 y 3 de Gobernanza de Datos. Está hecho con HTML, CSS y JavaScript; no necesita backend ni base de datos.

## Archivos
- `index.html`: contenido y secciones.
- `styles.css`: identidad visual y diseño adaptable.
- `script.js`: menú móvil y año automático.
- `assets/favicon.svg`: icono del sitio.

## Probar localmente
Abre `index.html` en un navegador. Para una prueba más fiel, puedes usar la extensión Live Server de Visual Studio Code.

## Publicar gratis con GitHub Pages
1. Inicia sesión en GitHub y crea un repositorio nuevo. Por ejemplo: `sustancias-locas`.
2. Si el repositorio es público, el código y la página también serán públicos. No subas contraseñas, claves, datos personales ni información privada.
3. Sube el contenido de esta carpeta al nivel principal del repositorio. `index.html` debe quedar en la raíz, no dentro de otra carpeta.
4. En el repositorio, abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
7. Espera a que termine la publicación. GitHub mostrará la URL pública en la sección Pages. Normalmente tendrá la forma `https://TU-USUARIO.github.io/sustancias-locas/`.
8. Cada vez que actualices los archivos y hagas commit/push a `main`, GitHub Pages volverá a publicar los cambios.

La interfaz de GitHub puede cambiar. Consulta la guía oficial: https://docs.github.com/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Nota académica y de rigor
- Sustancias Locas es un caso ficticio.
- La arquitectura, las políticas y los controles se presentan como propuestas académicas, no como controles ya implementados.
- Las cifras (3 fábricas, 12 líneas, 240 sensores y lectura cada 10 segundos) corresponden a los datos del caso.
- Los rangos de peligrosidad y alarmas en ppm no se inventan: deben verificarse con el Anexo A oficial del caso. La ficha de seguridad del benceno aporta información sobre peligros de la sustancia, pero no sustituye esa tabla.
- La misión y visión se presentan como propuestas, no como declaraciones oficiales de una compañía real.
- El sitio no contiene un formulario funcional ni recopila datos de visitantes.
